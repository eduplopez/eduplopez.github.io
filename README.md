## Sobre el proyecto

Esta web funciona como una presentación profesional y un currículum interactivo. Su diseño combina una estética de terminal retro con una estructura clara, accesible y responsive para mostrar:

- Perfil profesional y trayectoria.
- Stack tecnológico.
- Proyectos destacados.
- Servicios y áreas de trabajo.
- Idiomas.
- Información de contacto.

El sitio está construido como una web estática ligera, sin frameworks ni dependencias de ejecución, para que cargue rápido y sea fácil de mantener.

## Ejecutar en local

El proyecto no necesita un proceso de compilación ni un servidor backend.

1. Clona el repositorio:

   ```bash
   git clone https://github.com/eduplopez/eduplopez.github.io.git
   cd eduplopez.github.io
   ```

2. Abre `index.html` directamente en el navegador o inicia un servidor local. Por ejemplo, con Python:

   ```bash
   python -m http.server 8000
   ```

3. Visita [http://localhost:8000](http://localhost:8000).

Para editar el contenido principal, revisa `index.html` y los datos dinámicos definidos en `js/script.js`. Los estilos se encuentran en `css/styles.css`.

## Despliegue

El repositorio está preparado para publicarse con **GitHub Pages** desde la rama `main`. Al ser un sitio estático, GitHub Pages sirve directamente los archivos del repositorio sin pasos adicionales de build.
